
# FODTON Essential Institutional Website — MVP

Built for the paid **Essential Institutional Website** scope.

## Included
- Homepage
- About Us
- Professional Training Programmes
- Research, Policy & Data
- Home Care & Caregiving
- Events & Knowledge
- Management Team
- Partnerships
- Media
- Contact
- Basic appointment form UI
- Responsive frontend

## Not included in Essential scope
- Online payment integration
- Individual programme/course detail system
- LMS/student portal
- Admin analytics dashboard
- Advanced appointment workflow

## Run locally
```bash
npm install
npm run dev
```

Open http://localhost:3000
